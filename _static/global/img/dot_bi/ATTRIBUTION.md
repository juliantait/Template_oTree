## About this bundle
- 30 pre-rendered DOT-BI checks (`dotbi_01.gif` … `dotbi_30.gif`), copied byte-for-byte from the original `Pregenerated Checks/` — pixels unaltered.
- Files were renamed to **opaque ids** so the correct answer is not exposed in the served filename.
- The answer key (`opaque id → hidden number`) is in `answers.json` and must be kept **server-side only**.
